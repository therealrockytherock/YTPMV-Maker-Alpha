# YTPMV-Maker-Alpha

# 🎵 YTPMV Maker — FL Studio-Inspired

A browser-based **YTPMV (YouTube Poop Music Video) Maker** built with HTML, CSS, and JavaScript. Create chaotic, synced music videos directly in your browser with an interface inspired by **FL Studio**.

<img width="1172" height="834" alt="image" src="https://github.com/user-attachments/assets/77434ab4-15bc-49aa-8358-2c154865d383" />


## ✨ Features

* 🎧 Upload your own audio files
* 🎬 Upload video clips
* 🎹 FL Studio-inspired timeline/sequencer
* 🔊 Arrange and sync audio with video
* ✂️ Cut, move, and organize clips
* 🎵 Create YTPMV-style edits and music videos
* ▶️ Preview your project directly in the browser
* 💾 Save and load projects
* 🌐 Runs entirely in your browser
* 📦 No installation required

## ⚠️ Current State

**The video editor is NOT fully finished yet.**

The video editing side of the project is still heavily under development and may currently **look bad, rough, unfinished, or even terrible**. Some features may not work correctly, the interface may change significantly, and bugs are expected.

The music/audio editing features are the main focus right now. The video editor will be improved over time.

## 🎛️ FL Studio-Inspired Interface

The editor takes inspiration from the workflow of FL Studio, including a playlist-style timeline, tracks, clips, and music-production controls — but it's designed specifically for making **YTPMVs and video edits**.

> This project is **not affiliated with or endorsed by Image-Line or FL Studio**.

## 🚀 Getting Started

Download or clone the repository and open YTPMV Maker in your browser.

No server or complicated setup is required for the basic version.

## 🎯 Goal

The goal of this project is to make YTPMV creation easier by combining **video editing + music sequencing** into one simple browser-based tool.

Have fun making some absolutely ridiculous YTPMVs. 💀🎵
